mrnIF 산식 엔진

순위를 바꾸면 즉시 재계산됩니다
mrnIF = Σ { 100 × ( N − rank ) ÷ ( N − 1 ) } ÷ Σ ( SCI 논문 건수 )
N = 해당분야 SCI 저널 총 수 · rank = 해당 논문이 게재된 저널의 분야 내 IF 순위

참조값 아래 N과 rank는 JCR 미연동 상태의 데모 참조값입니다. 실제 운영 시 Clarivate JCR 연동으로 자동 채워집니다. 산식 연산 자체는 실제 로직 그대로이며, 값을 바꾸면 하단 평균이 즉시 갱신됩니다.
